# Сто комплиментов Ульяне

Страница-подарок: сначала букет, потом 101 комплимент, по одному за раз, на стеклянной карточке
поверх тёмного фона с медленно дышащим тёплым свечением. Тап в любом месте
или кнопка «Дальше» — следующая фраза. Внизу тихо идёт лента из тех же фраз.

**Открыть:** https://mynzhanov.github.io/ulyana/

## Дизайн

Собрано по архетипу **Ethereal Glass**: глубокий фон `#050505`, два мягких
орба (розовый и янтарный), карточка по приёму double-bezel — оправа и ядро
с концентричными радиусами, волосяная кромка, внутренний блик. Позади
карточки намечена стопка из двух силуэтов: 101 фраза читается как колода.

- Дисплейный шрифт — **Unbounded 300**, подписи — **Manrope**. Оба с настоящей
  кириллицей, проверено по подмножествам Google Fonts.
- Акцент один на всю страницу, задан одним токеном `--accent-rgb`.
- Все переходы на одной кривой `cubic-bezier(0.32, 0.72, 0, 1)`. Исключение —
  нижняя лента: бегущей строке нужна постоянная скорость, поэтому `linear`.
- Анимация только через `transform` и `opacity`. `backdrop-filter` висит
  только на «острове» — маленькой фиксированной области; на карточку он не
  поставлен намеренно, иначе движущееся свечение под ней заставляло бы GPU
  перерисовывать её каждый кадр.
- `prefers-reduced-motion` выключает свечение, ленту и появления.

## Что где

| `docs/og.png` | Карточка-превью 1200×630 для мессенджеров |

Подключение шрифтов берётся из `ulyana.html`, дублировать его в скрипте не
нужно; сборка падает с ошибкой, если наборы всё-таки разойдутся.

## Букет при входе

При заходе снизу протягивают букет: нежно-розовые и белые пионы и садовые розы
в розовой и белой бумаге, с атласным бантом и гипсофилой. Бутоны раскрываются,
из-за цветов выглядывают листья, падают лепестки, и рукой дописывается
«это тебе. люблю.» с сердечком. Потом открывается страница с комплиментами.

- Букет рисует код (`bouquetSVG()`), сид фиксированный — он каждый раз один и тот же.
- Лепестки залиты сплошным тоном, не градиентом: в Safari SVG перерисовывается
  целиком каждый кадр, и градиенты на ~300 лепестках роняли раскрытие до 26 fps.
  Со сплошным тоном в iOS Simulator — ровные 60 fps во всех фазах.
- Первый тап ускоряет сцену в 3.5 раза, второй открывает страницу. Без касаний
  букет стоит 11 секунд. Тап засчитывается на отпускании, поэтому щипок его
  не закрывает.
- Если страницу открыли в фоне (мессенджеры так делают), букет ждёт, пока её
  увидят. Ушла посреди сцены — вернётся, и сцена начнётся заново; если уже всё
  досмотрела — подарок просто дождётся её.
- Рукописный шрифт Marck Script грузится отдельным подмножеством только из букв
  записки (1.3 КБ). Сцена ждёт его не дольше 0.8 с.
- С «уменьшением движения» букет сразу стоит целиком, без падающих лепестков.

## Обращения

Имя в комплиментах не зашито. В строке стоит слот `{имя}`, и при каждом показе
туда встаёт одна из форм: **Ульяна, Ульяша, Уля, любимая, солнышко**. Одна и та
же фраза приходит то с «Улей», то с «солнышком». Одна форма не выпадает дважды
подряд.

```
{имя}, ты пахнешь как хорошее воскресенье
Ты умеешь прощать без напоминаний, {имя}
{имя: Ульяна, Уля, любимая}, ты как солнце — только не слепишь
```

- Слот в начале строки — первая буква становится заглавной («Солнышко, …»).
  В других местах «любимая» и «солнышко» пишутся строчными.
- `{имя: …}` — только перечисленные формы. Нужно, когда какая-то форма не
  подходит по смыслу: «солнышко» в строке, где уже есть «солнце».
- К слоту нельзя привязывать слова вроде «моё» или «милая»: у «солнышка»
  средний род, у остальных женский, согласование сломается.
- Список форм — `FORMS` в начале скрипта, дательный падеж для подписи в шапке —
  `DATIVE` рядом. Шапка тоже меняет форму, одну на заход: «Ульяне», «Уле»,
  «любимой»…

Сборка проверяет слоты и падает, если в строке два слота, неизвестная форма
или ограничение меньше чем из двух форм.

## Правки

Комплименты — простым списком в начале `<script>` в `ulyana.html`, по одному
на строку. После правки:

```
python3 build-site.py https://mynzhanov.github.io/ulyana
git commit -am "новые комплименты" && git push
```

Pages подхватывает пуш за минуту-полторы. Чтобы увидеть свежую версию сразу,
открывай с `?v=2` — CDN отдаёт HTML с `max-age=600`.
