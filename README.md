# Сто комплиментов Ульяне

Страница-подарок: 101 комплимент, по одному за раз, на стеклянной карточке
поверх тёмного фона с медленно дышащим тёплым свечением. Тап в любом месте
или кнопка «Дальше» — следующая фраза. Внизу тихо идёт лента из тех же фраз.

**Открыть:** https://mynzhanov.github.io/ulyana/

## Дизайн

Собрано по архетипу **Ethereal Glass**: глубокий фон `#050505`, два мягких
орба (розовый и янтарный), карточка по приёму double-bezel — оправа и ядро
с концентричными радиусами, волосяная кромка, внутренний блик. Позади
карточки намечена стопка из двух силуэтов: 101 фраза читается как колода.

- Дисплейный шрифт — **Unbounded 300**, подписи — **Manrope**. Оба с настоящей
  кириллицей, проверено по подмножествам Google Fonts.
- Акцент один на всю страницу, задан одним токеном `--accent-rgb`.
- Все переходы на одной кривой `cubic-bezier(0.32, 0.72, 0, 1)`. Исключение —
  нижняя лента: бегущей строке нужна постоянная скорость, поэтому `linear`.
- Анимация только через `transform` и `opacity`. `backdrop-filter` висит
  только на «острове» — маленькой фиксированной области; на карточку он не
  поставлен намеренно, иначе движущееся свечение под ней заставляло бы GPU
  перерисовывать её каждый кадр.
- `prefers-reduced-motion` выключает свечение, ленту и появления.

## Что где

| Файл | Зачем |
| --- | --- |
| `ulyana.html` | Исходник: тело страницы без `<head>`, годится как артефакт Claude |
| `build-site.py` | Собирает `docs/index.html` — добавляет `<head>`, метатеги, превью |
| `docs/` | То, что раздаёт GitHub Pages |
| `docs/og.png` | Карточка-превью 1200×630 для мессенджеров |
| `docs/icon-180.png` | Иконка для «Добавить на экран Домой» |

Подключение шрифтов берётся из `ulyana.html`, дублировать его в скрипте не
нужно; сборка падает с ошибкой, если наборы всё-таки разойдутся.

## Правки

Комплименты — простым списком в начале `<script>` в `ulyana.html`, по одному
на строку. После правки:

```
python3 build-site.py https://mynzhanov.github.io/ulyana
git commit -am "новые комплименты" && git push
```

Pages подхватывает пуш за минуту-полторы. Чтобы увидеть свежую версию сразу,
открывай с `?v=2` — CDN отдаёт HTML с `max-age=600`.
