# Сто комплиментов Ульяне

Пиксельная страница: бегущая строка с комплиментами, комплимент по центру
печатается по буквам, по небу плывут пиксельные сердечки, искры и смайлики.
Тап в любом месте — следующий комплимент и салют из сердечек.

**Открыть:** https://mynzhanov.github.io/Ulyana/

## Что где

| Файл | Зачем |
| --- | --- |
| `ulyana.html` | Исходник страницы: тело без `<head>`, годится как артефакт Claude |
| `build-site.py` | Собирает из исходника `docs/index.html` — добавляет `<head>`, метатеги и превью |
| `docs/` | То, что раздаёт GitHub Pages |
| `docs/og.png` | Карточка-превью 1200×630 для мессенджеров |
| `docs/icon-180.png` | Иконка для «Добавить на экран Домой» |

## Правки

Комплименты лежат простым списком в начале `<script>` в `ulyana.html`,
по одному на строку. После правки:

```
python3 build-site.py https://mynzhanov.github.io/Ulyana
git commit -am "новые комплименты" && git push
```

Через минуту-две Pages подхватит изменения.
